# Skills de Rservasroma para Claude Code

Este paquete trae 11 skills listas para usar en Claude Code, con la misma
estructura que ya usabas en Claude.ai (Anthropic Agent Skills).

## Cómo instalarlas

**Opción A — Solo para este proyecto:**
Copia la carpeta `.claude` completa a la raíz de tu proyecto de Claude Code.

**Opción B — Para todos tus proyectos:**
Copia el contenido de `.claude/skills/` dentro de `~/.claude/skills/` en tu
carpeta personal (créala si no existe).

## Skills incluidas

- rservasroma — copiloto general del ecosistema (código, contenido, negocio)
- superpowers — modo riguroso para tareas complejas (planificar antes de construir)
- ventas-rservasroma — respuestas de venta por WhatsApp/DM
- reels-virales-rservasroma — pack de reels virales
- romacrece-analisis — diagnóstico de cuentas de Instagram
- diseno-rservasroma — sistema de diseño UI/UX del ecosistema
- humanizador — reescribe textos para que no suenen a IA
- verificador-datos — fact-checking de textos antes de publicar
- optimizador-prompts — ordena ideas sueltas en prompts claros
- entrevistador-procesos — entrevista antes de construir un proceso nuevo
- skillultra — combina orden + planificación + verificación en una pasada

## Verificar que cargaron

Al abrir Claude Code en el proyecto, corre `/doctor` o pregúntale a Claude
qué skills tiene disponibles en la sesión.
